# Block App Updates 1.0.0

The first public release of Block App Updates.

## Highlights

- Block updates for individual App Store applications.
- Unblock them whenever you are ready to update.
- Stage several changes and refresh the App Store only once.
- See blocked applications in a separate Settings section.
- Automatically handle applications that have been reinstalled.
- TrollStore applications are excluded automatically.
- Supports rootless iOS 15 and later.

After installing or removing the package, select **Restart SpringBoard** in Sileo.
