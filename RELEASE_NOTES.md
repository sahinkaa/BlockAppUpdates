## What's new

- Preserve the existing Allow or Don't Allow notification choice of all jailbreak, TrollStore and TrollStore Lite apps after the App Store refresh, not only Sileo's.
- Trim stray whitespace from helper messages shown in alerts.

### Included from 1.0.4

- Automatically save and restore Home Screen folders and icon placement when applying changes. The restored layout persists across later resprings.
- Shorten the confirmation and show that the device will respring when the refresh is complete.

## Installation

Add [sahinkaa](https://sahinkaa.github.io/) to Sileo or Zebra and install or upgrade **Block App Updates**. The package manager selects the matching build. Both Rootless and native RootHide packages are attached below for manual installation.

Targets **iOS 15-26**. ichitaso tested this version on **iOS 16.5 Dopamine**, **iOS 17.5.1 Dopamine** and **iOS 26.0.1 RootHide**.

1.0.5 improvements by [ichitaso](https://github.com/ichitaso). See the [full changelog](https://github.com/sahinkaa/BlockAppUpdates/blob/v1.0.5/CHANGELOG.md).
